## 本次发现并处理的问题

1. **重复创建券失败**：上游用按 ID 排序后 one() 查询最大券，再加一；数据超过一条时抛 TooManyResultsException，并发分配也不稳。改为使用已有 SnowflakeIdGenerator 生成券 ID，两次连续冒烟通过。
2. **Spring 参数名**：锁与重复执行注解使用 SpEL 参数名，Maven 编译显式启用 parameters，配合 Spring 6 的参数发现。
3. **上传目录**：去掉上游机器硬编码路径，改为 JVM 属性覆盖或仓库内相对目录。
4. **本地依赖隔离**：生成专用分片数据源、独立 Redis/Kafka 端口和前缀，避免启动初始化碰原 hmdp 数据。
5. **SQL 首段会话变量**：导入生成文件时预设 saved_cs_client，兼容上游 SQL 首段恢复字符集的写法；原 SQL 保留。
6. **前端访问**：固定本地端口与回环代理地址，避免 localhost 的 IPv4/IPv6 解析差异。
